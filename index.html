Data provenance & limitations

GitHub Pages is static hosting. This single file has no Python backend, persistent server crawler, API secrets, or cross-user database. It refreshes the selected stock's GDELT public news request every minute while the browser tab is open.

Market universe and candles: attempts keyless TejHQ daily exchange snapshots and OHLCV (third-party service; may be unavailable or block cross-origin requests). Add official NSE/BSE CSV files for full directory details and known listing dates. Historical delisted securities need archive imports.

Social platforms: authenticated X, LinkedIn, Reddit and YouTube streams require authorised APIs and usually a secured backend. Direct platform search links are provided; you may import legally collected posts via CSV, with deduplication.

IPOs: upload current official IPO calendar CSV; the news radar is not an authenticated IPO issue list. Verify issue dates and subscription with NSE/BSE.

Prediction indicator: an unvalidated bilingual keyword/momentum heuristic, not a calibrated probability or trading recommendation. Price readings are end-of-day unless you navigate to an external live chart.

Data privacy: watchlist, imported records and story caches are saved locally in your browser (not on GitHub's server); do not upload private tokens to public HTML.
